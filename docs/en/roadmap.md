# Product Roadmap

Last updated: 2026-07-31.

The roadmap owns product phases only. Current priority is maintained in the
[backlog](backlog.md), and accepted runs belong in
[compatibility](compatibility.md).

## Phase 1: US8 with real controller metrics

Deliver one non-UniFi Linux bridge that an operator can add to UniFi Network as
an `US8`.

The phase exits when the same product bytes on current Stable and Release
Candidate are discoverable, adoptable, connected, and show real link state,
speed, counters, and rates from the named local source without permitting host
provisioning.

## Phase 2: Usable Linux release

Deliver the accepted behavior as an installable package and operator path on a
supported Linux host.

The phase exits when installation, supported bridge configuration, packaged
service startup, adoption, visible metrics, limitations, and recovery work as
one documented journey.

## Phase 3: Further representations on demand

Add another profile or platform only for a concrete operator outcome. Each new
representation needs a named read-only source, an explicit safety decision, and
its own dynamic Stable/RC acceptance; evidence from a neighboring model does
not expand product scope.
